# Scientific + DOCX (scientific-agent-skills)

## Overview
Provides domain-specific scientific formatting for scientific papers, lab reports, and technical analyses. Handles scientific notation, SI dimensional units, chemical formulas, physical constants, and empirical data tables.

## Core Capabilities
1. **Scientific Notation**: Formats numbers in scientific exponential notation (e.g., $1.5 \times 10^{-4}$, $6.022 \times 10^{23}$).
2. **SI Measurement Units**: Standardizes base and derived SI units inside roman math blocks ($\text{m/s}^2$, $\text{kg/m}^3$, $\text{mol/L}$, $\text{kJ/mol}$, $\mu\text{m}$, $\text{kHz}$, $\text{W/m}^2$, $\text{Pa}$).
3. **Chemical Molecular Formulas**: Subscripts stoichiometric coefficients and charges ($\text{H}_2\text{O}$, $\text{CO}_2$, $\text{C}_6\text{H}_{12}\text{O}_6$, $\text{H}_2\text{SO}_4$).
4. **Experimental Uncertainties**: Standardizes $\pm$ notations and confidence intervals (e.g., $12.45 \pm 0.05\text{ g}$).
5. **Empirical Measurement Tables**: Aligns decimal columns and preserves measurement precision.
